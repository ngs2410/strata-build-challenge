## Rubrics
Change-type rubric. Every detected Change.change_type must be one of the five values below.

Perspective rule. Strata interprets every regulatory change from the REGULATED ENTITY's perspective — the aggregator, utility, hospital, broker, etc. whose compliance burden the system tracks. When a rule changes, the question is ALWAYS "does the regulated entity now have to do more, less, or the same?" — NOT "does the regulator have more or less authority?"

A regulator-side relaxation that creates de facto new burden on the regulated entity is a TIGHTENING of the entity's obligation. A regulator-side expansion that lifts a burden the entity previously faced is a LOOSENING. If the direction is still ambiguous after applying this rule, drop confidence to 3 and name the ambiguity in confidence_rationale.

- added: A wholly-NEW STANDALONE obligation present in the new version that did not exist in the prior version. The regulated entity now has to perform an ACTION they had no corresponding duty to perform before. An added obligation COULD stand alone even when it is written into the same paragraph as other obligations. Does NOT apply when a new clause modifies the parameters (timing, required data elements, thresholds, scope) of an EXISTING obligation — those are tightened or loosened. prior_citation must be null.
- removed: An obligation or clause that existed in the prior version and is gone in the new version. The regulated entity no longer has to do something they previously had to do. new_citation must be null.
- tightened: An existing obligation whose parameters got stricter FOR THE REGULATED ENTITY — common cases: adding a timing requirement (e.g. '... within 30 days'), adding a required data element to a reporting list (e.g. '... including the point of interconnection'), lowering a threshold, widening scope of who/what is covered, adding a precondition that must be satisfied. Also includes regulator-side changes (e.g. 'the RTO may now impose a minimum size') that create de facto new burden on the entity. If multiple parameters tighten the SAME underlying obligation, group them into ONE change (see Additional rules in the task prompt).
- loosened: An existing obligation whose parameters got laxer FOR THE REGULATED ENTITY — relaxed timing, dropped required data elements, raised threshold, narrowed scope, removed precondition. Also includes regulator-side changes that lift a burden the entity previously faced. If multiple parameters loosen the SAME underlying obligation, group them into ONE change.
- cosmetic: A re-wording, re-numbering, or re-formatting that preserves the obligation unchanged in substance. The regulated entity's compliance burden is identical before and after.

Confidence rubric (0-5 integer). Self-report your confidence in the conclusion AND set confidence_rationale naming which rubric level you picked and why. Over-confidence is a worse failure than under-confidence — when in doubt, drop one level.

- 5: Unambiguous — the cited passages state the conclusion verbatim.
- 4: Strongly supported — one short inferential step from the cited passages.
- 3: Reasonable — the cited passages support the conclusion but a reviewer might legitimately disagree.
- 2: Weak — surface signals point this way but the inference is thin.
- 1: Speculative — judgement call with limited anchor in the cited text.
- 0: Guess — no defensible anchor in the cited text; escalate.
